# KTUL reference study

Generated by model 0.3.0-screening, scenario schema 2, weather snapshot schema 1. Grownetics Archive document, light by default regardless of OS theme.

This is observed weather-side thermodynamic opportunity, not simulated indoor operation, HVAC sizing or an operating-cost/energy-savings estimate. The archived period has 6087 expected hours, 6064 observed valid hours and 23 missing, from 2026-01-01T06:00:00.000Z to 2026-09-11T21:00:00.000Z exclusive. It is not a complete annual record.

Open ktul_2026_operating_hours_report.html for the charts, or the Markdown report for the methods. Every CSV keeps its missing weather as gaps rather than filling them. Units and source provenance are in manifest.json. The independent NOAA daily comparison has 251 records, and the differences between sampling conventions are not calibration corrections.

What is kept here is the study's findings: the two reports, the mode summary, the monthly percentiles, the episode list, the daily exposure table, the sensitivity cases and the NOAA cross-check. The hour-by-hour working is not kept, because the fetch and regenerate commands below rebuild it. That means a refresh is a two-step job: retrieve the observations first, then rerun the study.

From the application folder: `node scripts/reference-study.mjs [snapshot.json] [output-directory]`. Refresh observed weather and NOAA data with `node scripts/fetch-observed.mjs [start-date] [end-date]`. Refreshing changes the archived period and must be reviewed separately.
